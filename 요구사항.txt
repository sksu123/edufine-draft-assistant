2가지 기능을  추가하려고 해.
1. 교사용 기안 페이지에서 '에듀파인 품의서 초안 확정'이라고 하면 행정실에서 작성교사명, 품목내역과 업로드된 견적서 및 장바구니 사진을 확인할 수 있는 기능(사진은 확대가 가능해야 해.) 그리고 이 것을 확인하는 화면에서 해당 건에 대한 지출결의금액을 입력하면 해당 산출내역 예산이 감소되어서 반영되어야 해. 지출결의까지 진행된 후 건별로 '완료' 버튼으로 처리를 할 수 있게 해주고, 완료를 누르면 '해당 건의 첨부파일을 삭제하겠습니까?' 라는 팝업창이 출력되고, 이걸 누르면 장바구니 이미지나 견적서가 storage에서 삭제되도록 하고싶어.
2. '에듀파인 품의서 초안 확정'을 누르면 품의서 본문을 생성하시겠습니까? 팝업이 나오고 여기서 '예'를 누르면 품의서 본문이 작성되어서 바로 복사할 수 있게 해줘. 품의서 본문을 생성하겠습니까?에서 '예'를 선택하면 바로 작성하는 것이 아니라, 몇 가지 선택사항이 출력되어야해.
 1) 품의명(자주 쓰이는 품의들은 미리 부서장님들이 admin페이지에서 '행사명, 품의제목, 관련문서번호, 결재일, 품의 시작문구, 목적'을 입력해두어서 드롭다운으로 선택하면 해당 부분이 바로 반영될 수 있도록, 관련문서가 2개 이상일 수 있으니 +버튼 넣어서 + 누르면 행이 추가되도록하고, 기존에 등록된 품의가 아닌 경우 '직접입력'을 선택해서 품의 제목, 품의 시작문구를 직접 입력할 수 있도록, 디폴트값은 직접입력으로
  2) 대상: 1학년, 2학년, 3학년 버튼을 출력하고 해당 버튼을 누르면 1반, 2반, 3반... 체크박스로 선택할 수 있게. 전체선택 기능 있어야해. 특정 반만 체크하면 품의서 본문의 '대상' 부분에 해당 학급만(예를 들어 1학년을 선택한 후 2반, 3반 체크시 품의서 본문 '대상 부분에 '1-2, 1-3'와 같이 출력, 1학년 전체학급 선택시 대상 부분에 '1학년'으로 출력, 클릭순서와 관계 없이 오름차순으로 학급 및 반 정렬되어서 작성되도록, 1학년, 2학년, 3학년 선택 화면에서 전체선택을 누를 경우 품의서 본문 '대상' 란이 '전교생'으로 출력 (admin페이지에 학년별 학급 사전에 입력하면 이것 기반으로)
  3) 일시: 시작일시, 종료일시를 각각 캘린더와 시간선택 드롭다운으로 제공, 수동입력도 가능하게
  4) 장소: 직접 입력할 수 있게
  5) 구매처: admin페이지에서 학교에서 자주 사용하는 사이트 목록 기입해두면 드롭다운 제공. '직접입력' 선택지 넣고 이것을 선택하면 직접 선택할 수 있게(직접입력을 디폴트값으로)
  6) 붙임: 붙임파일이 없을 수도 있고 여러개일 수도 있으니 '+' 버튼 눌러서 행 추가
  
  이것을 기반으로 복사용으로 출력되는 품의서 본문 내용은 아래 양식을 따라줘.
  
  1. 관련: ((관련문서번호(결재일)))부서장이 admin에 미리 세팅한 사업의 경우 사업명 선택시 관련문서번호(결재일)로 출력, 그렇지 않으면 공란)), 만약 관련문서가 2개 이상이면 '가.', '나.'로 번호 달기.(1.시작 위치보다 1칸 더 띄우고 가., 나. 시작)
  2. ((품의서 시작문구))(예를 들어 과학과제연구 실험물품을 구입하고자 합니다.(부서장이 사전 입력한 문구.
  가. 행사명: ((부서장 사전 등록한 경우 해당 행사명, 없으면 공란))
  나. 일시: ((캘린더 및 시간선택 드롭다운으로 선택한 시간-끝나는 시간)), 끝나는 시간 입력안할 경우 시작시간만 출력되도록
  다. 장소: ((사전입력))
  라. 대상: ((사전 입력 대상))
  마. 금액: ((장바구니 스캔을 통해 입력된 총액))원
  바. 목적: ((부서장 사전입력 내용, 없으면 공란으로))
  사. 구매처: ((사전선택 내용)
  
  만약 행사명, 일시, 장소, 대상, 금액, 목적, 구매처 중 사전에 입력되지 않은 것이 있다면 해당 부분을 공란으로 두고 색인(가, 나, 다... 등)을 하나씩 당겨줘.
  만약 붙임 파일이 없다면 앞의 본문 끝에 .  끝.(끝 앞에 띄어쓰기 2칸)으로 본문을 마무리하고, 
  1)붙임파일이 하나인 경우: 앞의 본문에서 줄바꿈 2회 후 '붙임  붙임파일명 1부.  끝.', (붙임파일명 앞 띄어쓰기 2칸), 
  2)붙임파일이 둘 이상인 경우: 앞의 본문이서 줄바꿈 2회 후 
  '붙임  1. 붙임파일명1 1부
           2. 붙임파일명2 1부.  끝.'형태로 마무리해줘. 붙여넣었을 때 같은 계열(1., 2.,..), (가., 나., 다.,...)은 육안으로 보았을 때 시작 x위치가 동일하게 통일되어야 해)))))
